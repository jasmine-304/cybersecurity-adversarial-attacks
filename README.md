# AI and Cybersecurity - Adversarial Attacks

## Overview
This project implements multiple adversarial machine learning attacks using PyTorch.

## Implemented Attacks
- White-box targeted attacks
- Grey-box transfer attacks
- Universal adversarial perturbations (UAP)
- Adaptive attacks against defended models

## Techniques used
- PGD-based optimisation
- Ensemble surrogate models
- Transfer-based adversarial attacks
- EOT-style adaptive optimisation

## Environment Used
- Python
- PyTorch
- Kaggle - using the free gpu

## Additional Notes
The grey-box attack followes the constraints listed in the assignment description and does not use target-model gradients during optimisation.
